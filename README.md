# Oluwadunsin Olatunji — Portfolio

Personal portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Pages

- Home: introduction and featured engineering work.
- About: education, technical skills, experience, and résumé link.
- Projects: three original breadboard circuit photographs.
- Contact: professional email and résumé link.

Open index.html in a browser to preview locally. No installation or build is required. Shared styles and scripts live in assets/, and original project photographs live in assets/images/.
